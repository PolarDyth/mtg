# Battlefield Arrows — Cockatrice-style attack/target indicators

Players draw synced arrows between battlefield cards (or card → player) to declare attacks, blocks, and targets. Rendered as curved, per-player-colored SVG paths on a full-table overlay. Greenfield feature — no annotation state exists yet.

## Decisions made on your behalf (veto anything)
1. **Lifecycle: auto-clear on turn change.** Arrows vanish when anyone passes the turn; also clearable manually anytime; auto-pruned when an endpoint card leaves the battlefield or a target player leaves; cleared on END_GAME.
2. **Gesture: right-drag + menu fallback.** Press-and-drag right button from any battlefield card (Cockatrice muscle memory); plain right-click still opens the card menu (now on right-button *release* without movement — needed to disambiguate click vs drag). A "Draw arrow to…" context-menu item enters click-to-target picking mode (trackpad-friendly, discoverable).
3. **Targets: card→card and card→player** (arrow ends at a player's board header — "these attack you").
4. **Redraw semantics:** drawing from a card replaces that author's previous arrow from the same card (one outgoing arrow per card; incoming unlimited — double-block works).
5. **Permissions:** anyone may clear any arrows (collaborative board, no-rules philosophy). **No chat log lines** for arrows (visible state; avoids spam).

## 1. Protocol — `shared/src/index.ts` (change shared first)

```ts
export type ArrowTarget = { uid: string } | { playerId: PlayerId };
export type Arrow = {
  id: string;
  playerId: PlayerId;   // author; arrows render in the author's chat color
  fromUid: string;      // source battlefield card (any player's)
  to: ArrowTarget;
  at: number;
};
```
- `Action` union += `{ type: "DRAW_ARROW"; fromUid: string; to: ArrowTarget }` and `{ type: "CLEAR_ARROWS"; id?: string; playerId?: PlayerId }` (id → remove that arrow; else playerId → that author's; else all).
- `GameView` += `arrows: Arrow[]` — fully public (battlefield uids are already visible to every viewer; no hidden-info filtering needed).

## 2. Server — pure engine

- `engine/state.ts`: `Game` += `arrows: Arrow[]`, initialized `[]` in `createGame`.
- `engine/actions/internal.ts`: `MAX_ARROWS = 40`; `pruneArrows(game)` — filters arrows whose `fromUid`/`to.uid` card is no longer on any battlefield or whose `to.playerId` is no longer seated.
- `engine/actions/cards.ts` (card-centric → cards domain):
  - `drawArrow`: `fromUid` and `to.uid` must be cards **on some player's battlefield** (any owner — reuse/extend `findCard` in state.ts, checking zone), `to.playerId` must be seated, no self-target; drop the author's existing arrow with same `fromUid` (replace); enforce `MAX_ARROWS`; push `{ id: randomId(ctx.rng), playerId: actor.id, fromUid, to, at: ctx.now() }`.
  - `clearArrows`: id (err "arrow not found" if missing) / playerId / all.
  - Both added to `cardsHandlers` (`satisfies Partial<HandlerMap>`).
- `engine/actions/index.ts`: after any handler returns ok → `pruneArrows(game)` (single choke point; stays pure).
- `engine/actions/game.ts` (`nextTurn`) and `admin.ts` (`endGame`): `game.arrows = []`.
- `engine/view.ts`: `personalize` returns `arrows: game.arrows`.

## 3. Frontend

- `components/game/arrowGeometry.test.ts` — bow-side consistency, head angle, zero-distance edge.
- `components/game/ArrowLayer.tsx` — `<svg className="pointer-events-none absolute inset-0 z-10 h-full w-full">` mounted **inside Battlefield's root div** (spans all bands in every mode incl. maximize overlay). Props `{ arrows, players, you, onRemove }`. `useLayoutEffect` resolves each arrow's endpoints from live DOM (`[data-card-uid=…]`, `[data-player-head=…]` rect centers, viewport→svg-local) — re-runs per snapshot (props change identity) + `ResizeObserver`; skips arrows whose endpoints aren't mounted (e.g. hidden in duel focus). ## 6. Acceptance criteria
1. Right-drag from any battlefield card shows a live rubber band in your color; release on a card/player commits a synced curved arrow for all players, colored per author, animated in.
2. Plain right-click still opens the menu; "Draw arrow to…" + click targeting works; Escape cancels cleanly.
3. Arrows track their cards across drags and stay correct in all view modes and after resize.
4. Turn pass clears arrows; clear-all button and per-arrow delete work; arrows vanish when their card leaves play or a target player leaves; END_GAME resets.
5. `npm test` green, `npx tsc --noEmit` clean in both workspaces, `npm run build` passes.
