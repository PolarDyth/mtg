## Part 2 — Identity kit (fanned-trio mark)

**The mark**: three rounded-rect card fronts fanned (−12° / 0° / +12° from a shared base), center card emerald-500 (#10b981), side cards zinc-500/600, on a zinc-900 (#18181b) rounded-square background. Two tiers:
- **Glyph** (simplified): three solid rects, no borders — the 16px favicon variant.
- **Mark** (full): card borders + a subtle pip/inner frame on the center card — for in-app use ≥24px and the OG image.

**New files** (Next 16 App Router metadata conventions — icons auto-served, no `<link>` tags needed):

```
frontend/src/app/icon.tsx            ← favicon set via next/og ImageResponse (32/48px), glyph tier
frontend/src/app/apple-icon.tsx      ← 180×180 touch icon, glyph tier
frontend/src/app/opengraph-image.tsx ← 1200×630: zinc-900, full mark + "Cardessa" wordmark + tagline
frontend/src/app/manifest.ts         ← PWA: name "Cardessa", theme #18181b, background #09090b
frontend/src/components/Logo.tsx     ← inline SVG component (mark + wordmark variants)
```

**Deleted**: `frontend/src/app/favicon.ico` (stock Next triangle — replaced by `icon.tsx`), `frontend/public/{file,globe,next,vercel,window}.svg` (template leftovers).

**Integration**: `page.tsx` header swaps bare "Mythic Table" text → `<Logo />` (mark + wordmark, ~24px) + "Cardessa"; `layout.tsx` metadata gains `applicationName`, `themeColor` (#18181b), and the OG image is auto-wired.

Satori constraint honored: `icon.tsx`/`opengraph-image.tsx` render with plain flex divs + `transform: rotate` (satori-safe); the fancy SVG stays in `Logo.tsx` where real SVG works.
