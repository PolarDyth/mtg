- **`send()`** (`ws.ts:335-337`) — backpressure:
  ```ts
  const SEND_BUFFER_LIMIT = 4 * 1024 * 1024;
  function send(ws: WebSocket, msg: ServerMessage): void {
    if (ws.readyState !== ws.OPEN) return;
    if (ws.bufferedAmount > SEND_BUFFER_LIMIT) {
      ws.terminate(); // stopped reading — drop instead of buffering in RAM
      return;
    }
    ws.send(JSON.stringify(msg));
  }
  ```
  Safe during `broadcast()`'s `Set` iteration: `terminate()` fires `close` asynchronously, so the `conns.delete` happens after iteration.

## 2. #60 — edge-case batch (SEC-11..14)

**`server/src/seating.ts`** (new, pure — follows the `ratelimit.ts`/`netguard.ts` extraction precedent):
```ts
import type { Game } from "./engine/state";

type ConnLike = { game: unknown; playerId: string | null };

/** Case-insensitive display-name collision with a seated player. */
export function nameTaken(game: Game, name: string): boolean {
  const n = name.trim().toLowerCase();
  return game.players.some((p) => p.name.trim().toLowerCase() === n);
}

/** True when some OTHER connection still holds this seat (multi-tab rejoin):
 * on close we must not mark a seat disconnected while a live socket owns it. */
export function seatStillHeld(conns: Iterable<ConnLike>, exclude: ConnLike, playerId: string): boolean {
  for (const c of conns) {
    if (c !== exclude && c.game === exclude.game && c.playerId === playerId) return true;
  }
  return false;
}
```

**`server/src/ws.ts`** — three insertions:

1. **Duplicate names** (SEC-11) — in the `join` branch after the `isBanned` check (`ws.ts:245-247`), before `seat(...)`:
   ```ts
   if (nameTaken(game, name)) return failJoin(conn, "that name is already taken at this table");
   ```
   Routed through `failJoin` so it inherits the per-conn (5/10s) and per-IP (10/60s) join throttles — name-griefing is adjacent to code-sweeping. Semantics: a disconnected-but-unswept seat still holds its name (impersonation risk stands until lobby GC frees it); `rejoin` bypasses the check (it's the same player, by token).

2. **Rejoin ban check** (SEC-12) — in `rejoin` after the player lookup (`ws.ts:258`), before any mutation:
   ```ts
   if (isBanned(game, player.name, conn.ip)) return sendError(conn, "you are banned from this table");
   ```
   `sendError` (not `failJoin`) to match the issue text and existing rejoin error style — tokens aren't sweepable.

3. **Multi-socket close race** (SEC-13) — in the close handler after the `player` lookup:
   ```ts
   if (seatStillHeld(conns, conn, player.id)) {
     rooms.touch(game.code);
     return; // another socket owns the seat — leave it connected
   }
   ```
   (This sits inside the new try/catch body from §1.)

**Frontend decode 500** (SEC-14) — `frontend/src/lib/roomCode.ts` (new):
```ts
/** Decode a room-code path segment defensively: %ZZ / truncated escapes throw
 * in decodeURIComponent; a bad URL should degrade to a rejected join, not a
 * server-component 500. */
export function decodeRoomCode(raw: string): string {
  try {
    return decodeURIComponent(raw).trim().toUpperCase();
  } catch {
    return raw.trim().toUpperCase();
  }
}
```
`page.tsx:9` becomes `<GameClient code={decodeRoomCode(code)} />`. A garbage code then flows to the server, fails `isValidCode`, and the user sees the existing "Can't sit down" fatal card — no `error.tsx` needed.
